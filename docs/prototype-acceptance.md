### Контролируемые проверки в DevTools

Используй отдельную вкладку с локальным `index.html`. В Console Chrome `queryObjects(TankCore.Game)[0]` возвращает игровой экземпляр. Выражения ниже предназначены для тестовых сцен. Перед каждым сценарием перезагрузи страницу.

- **Последний снаряд (#9).** Выполни фрагмент ниже дважды, с `hp = 12` и `hp = 240`. Перед попаданием виден этап долёта последних снарядов. Затем откроется поражение с причиной или победа с 228 HP. На обоих экранах «Играть ещё раз» возвращает первую подготовку и полный запас HP. Проверенный драйвер продвигал эти кадры отдельно, чтобы прочитать итоговые значения.

```js
{
  const g = queryObjects(TankCore.Game)[0];
  const hp = 12;
  g.waveIndex = 7;
  g.startWave();
  g.enemies = [];
  g._spawnQueue = [];
  g.base.hp = hp;
  g._shoot({ id: 'fixture', x: 8.5, y: 13.5 }, g.base, 'enemy', 10, 12, 6);
}
```

- **Срок и продление (#10).** В подготовке выполни фрагмент ниже, затем поочерёдно выбери два первых корпуса. Подписи на поле и в карточке должны показывать срок до 3 и 4. Выбери третий корпус донором, наведи или перейди Tab на подтверждение укрепления первого корпуса. Ожидаются расход донора, 1 → 31 HP и срок до 4. Подтверди, затем нажми Ctrl+Z. При старте волны кнопка отмены становится недоступной. Для проверки за пределами финала перезагрузи вкладку, замени `g.waveIndex = 2` на `g.waveIndex = 7`, задай срок `8` всем трём корпусам, для первого замени HP на `30` и передай `type: x === 12.2 ? 'heavy' : 'medium'` в `_killEnemy`. Предпросмотр даст 90/120 HP и срок до 9 с предупреждением, подтверждение применит результат.

```js
{
  const g = queryObjects(TankCore.Game)[0];
  g.waveIndex = 2;
  for (const [x, y, hp, expiresAfterWave] of [[12.2, 13.4, 1, 3], [11, 13.4, 60, 4], [4.2, 6.5, 60, 4]]) {
    g._killEnemy({ type: 'medium', x, y });
    Object.assign(g.wrecks.at(-1), { hp, expiresAfterWave });
  }
}
```

- **Первый корпус (#12).** Начни волну 1. Создай гибель среднего в зоне через `g._killEnemy({type:'medium', x:3, y:2.2})`, предварительно присвоив `g = queryObjects(TankCore.Game)[0]` через `const` в Console. Корпуса и подсказки быть не должно. В одном блоке Console вызови `_killEnemy` для среднего в (5,7; 6,5) и тяжёлого в (20; 6,5), затем уничтожь первый через `g._applyHit({kind:'wreck', object:g.wrecks[0]}, {team:'player', damage:60})`. Подсказка должна относиться к разрушенному первому корпусу. Для контроля паузы нажми Esc до истечения четырёх секунд, подожди более четырёх секунд и продолжи. Для контроля отложенного обучения уничтожь оставшийся корпус, обнули длины `g.enemies`, `g.bullets` и `g._spawnQueue`, затем вызови `g._completeWave()` в тестовой вкладке. Во второй подготовке инструкции ещё нет. Начни волну 2, создай пригодный корпус через `_killEnemy` вне зоны, снова очисти эти три массива и вызови `_completeWave()`. В подготовке 3 появится инструкция. Перезапусти попытку и снова создай корпус вне зоны, чтобы увидеть первый показ.

### Звук и автономность

- В обычной волне 1 и при переключении звука записан выход Chrome через отдельный PipeWire monitor, PCM 48 кГц, моно, 16 бит. Изначально звук и выстрелы после выключения дали цифровой ноль. Включение, повторное включение и старт волны дали по 90,8 мс сигнала с ранней частотой 400 Гц. Стрельба со звуком дала 377,7 мс между первым и последним отсчётами выше порога, ранняя частота 110 Гц. В журнале четыре выстрела за две серии. Повтор в браузере — открыть новую вкладку, включить, выключить и включить звук, начать волну, удержать ЛКМ около 460 мс, выключить звук и повторить стрельбу.
- В контрольных сценах записаны попадание (36,4 мс, 600 Гц в раннем окне), уничтожение лёгкого (151,6 мс, 140→70 Гц), создание корпуса (201,7 мс, 140→530 Гц), разрушение корпуса (146,8 мс, 570→190 Гц) и совмещённое событие (201,6 мс, 140→530 Гц).
