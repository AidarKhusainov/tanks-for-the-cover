# Проверки общих правил боя #33

Проверки относятся к основному `index.html`. Контрольные сцены задают начальные координаты и HP, затем используют игровую симуляцию. Состав и расписание основной карты сохранены. Калибровка двух карт и кампаний относится к #34, человеческие сессии — к #14.

## Симуляция

```bash
node --test tests/shared-breach.test.cjs tests/shared-firing.test.cjs tests/heavy-priority.test.cjs
node --test tests/waves.test.cjs tests/dodge.test.cjs tests/attempt-log.test.cjs
npm test
```

| Сцена | Что наблюдать |
| --- | --- |
| Одна развилка, разные HP | Дешёвый пролом побеждает длинный обход. При более прочном корпусе обход быстрее. Обе оценки относятся к первому возможному выстрелу по базе. |
| Корпуса последовательно и за поворотом | Огонь по дальнему корпусу становится возможен после расчистки ближнего и нового подхода. В расчёт входят только доступные стрелки, их перезарядка и долёт. |
| Два прострела | При выстроенных в колонну средних на открытом участке задний смещается. Оба танка действительно поражают один и тот же корпус, базу или игрока. В развилке с корпусом 64 HP тяжёлый идёт к назначенной огневой позиции из-за угла и участвует в расчистке. |
| Один прострел | Передний держит огонь в коридоре шириной 1,6 единицы. Задний получает свободный луч после гибели переднего. Движение игрока и уклонение обновляют зарезервированную позицию. |
| Добивание, перестрелка и потеря цели | Тяжёлый с 20 HP добивает базу с 20 HP до ответа игрока, дважды поражает базу с 40 HP с обычной перезарядкой и переключается на игрока, когда добивание слишком долгое. Стена, союзник, потеря дальности и малая флуктуация прицела проверяются отдельно. |
| Подготовка | Средний корпус даёт двигатель или ствол, тяжёлый — броню. Установка расходует корпус. Замена и отмена восстанавливают фактическую дальность и состояние снимка. Возвращение сохраняет модуль, новая попытка очищает слот. Ремонт 25/45 HP проверяется при дефиците, ограничении 240 HP и полной базе. |
| Точная дальность | Точка контакта на 6,75 попадает со стволом. Выстрел за пределом дальности исчезает. Урон, скорость и перезарядка прежние. Средний начинает проверку уклонения после первого сегмента полёта и у удлинённого снаряда. |

Две оценки времени полезно сопоставлять с `ai_route` в журнале. `enemy_firing_position` отмечает выбор позиции, а `heavy_target` — смену цели или её причины. Координаты записываются в системе поля с осью Y вниз.

## Пороги первой настройки

- Маршрут переоценивается при изменении геометрии корпусов и каждые 0,6–0,72 с, пока результат может измениться. Разброс интервалов распределяет работу для колонны между шагами. Текущий выбор сохраняется при выигрыше альтернативы до 0,55 с. Контрольная развилка удерживает путь при малом выигрыше и переключается после более существенной потери времени или выбытия стрелка. Локальная группа включает появившиеся танки с одного входа на расстоянии до 6 единиц при прямом статическом соединении. Это ограничивает расчёт соседями у развилки. Оценка движения добавляет 0,13 с за поворот на 90° и 0,65 с за занятую стоящим танком траекторию. Фактическое движение проверяет столкновения на каждом шаге.
- Позиции для свободного луча проверяются на расстояниях 0,75, 1,25, 1,75 и 2,25 единицы, повтор поиска после неудачи — через 0,25 с. Этот диапазон даёт заднему танку боковой прострел на открытом участке и сохраняет очередь в узком коридоре.
- Локальная дуэль тяжёлого начинается в пределах 7 единиц от контура базы. Для добивания оставлено до 2,75 с, чтобы успевали два штатных выстрела с одной перезарядкой и долётом. Краткий уход прицела удерживает угрозу до 0,2 с при доступном игроке. Запас 0,08 с на переключение обратно к добиванию стабилизирует выбор при близких временах.

Поиск сравнивает свободный, короткий и взвешенный по HP геометрические варианты, а время группы оценивает для каждой найденной траектории. Для ближайших к текущему состоянию лучей используется боевая геометрия. Дальнейшее перемещение союзников, очереди и будущие прострелы оцениваются локально. Итог уточняется в бою по фактическим позициям.

## Браузер и автономный HTML

1. Откройте основную игру, проверьте ввод WASD, щелчок для выстрела, паузу и начало волны. В подготовке включите прогноз, смените вход и тип, затем проверьте обновление текста и линии. При выбранном проломе круг отмечает первый корпус.
2. Щёлкните средний корпус. Наведите на «Удлинённый ствол» или перейдите к кнопке клавишей Tab. Сверьте 6,75 единицы, отметки расхода и дальности. Установите ствол, выберите другой средний корпус и сравните предпросмотр двигателя. После замены Ctrl+Z возвращает ствол. Ещё одна отмена возвращает пустой слот и дальность 6.
3. Наведите на ремонт и сверьте обещанное и фактическое восстановление. Для полной базы показано +0 HP, корпус расходуется. Через Ctrl+Z верните его. Выгрузите JSON и сверьте `buildId`, `configuration.game.mapId`, `mapVersion`, модуль, дальность и связи `undo.actionSequence`.
4. Раздайте `index.html` через `python3 -m http.server 8765 --bind 127.0.0.1`, нажмите «Скачать для игры офлайн» и сверьте файл через `cmp index.html tank-prototype.html`. Остановите раздачу, включите Offline в DevTools и откройте скачанный файл через `file://`. Проверьте старт волны, управление, выстрел и отсутствие внешних запросов или ошибок страницы.
5. Машинный прогон основной кампании со штатным браузерным вводом запускается командой `node tools/verify-campaign.cjs index.html /tmp/tanks-33-campaign east`. Второй аргумент — новый каталог для журнала, последовательности ввода и снимков.
