# Editor Playtest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Запускать созданную в редакторе карту в настоящей игре одним нажатием и сохранять черновик для дальнейших изменений.

**Architecture:** Валидатор и преобразователь редакторского JSON добавляются в существующий inline API TankCore. Редактор передаёт снимок в URL fragment; игра создаёт отдельную конфигурацию, сохраняя штатные карты. localStorage используется только для черновика с явной обработкой отказа.

**Tech Stack:** Существующие HTML/CSS/JavaScript, Node.js >=20, встроенный node:test; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-11-23-editor-playtest-design.md`

## Global Constraints

- Сохранить автономный `index.html` и автономный редактор, существующие три inline script-блока игры.
- Формат `tanks-map-editor` v1, поле 28 × 18, не более 300 объектов.
- Один спавн A, существующие восемь волн / 66 противников и интервал 2,5 с.
- Не менять боевые правила и штатные карты; не добавлять зависимости.

## Review Focus

- Точная геометрия: координаты спавна/игрока в редакторе обозначают угол прямоугольника, в игре — центр.
- Ошибочные карты: неправильные типы/размеры/числа, дубли ID, занятые стартовые позиции, непроходимая схема.
- Потеря черновика: перезагрузка, отказ localStorage, возврат из старого теста к более свежим изменениям.
- Переходы: повторный тест, обычные карты после пользовательской, импорт JSON, повреждённый fragment.
- Автономность: запуск пары HTML через file://, отсутствие сетевых ресурсов, сохранение офлайн-игры.
