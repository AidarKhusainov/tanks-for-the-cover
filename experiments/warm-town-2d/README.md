# Тёплый обжитой город

Скачайте [tanks-warm-town.html](tanks-warm-town.html) кнопкой **Download raw file** в GitHub и откройте его в настольном браузере. Через `file://` файл работает без сервера, сети и дополнительных файлов. [Открыть сборку из коммита `ce8b7a5` в браузере](https://htmlpreview.github.io/?https://raw.githubusercontent.com/AidarKhusainov/tanks-for-the-cover/ce8b7a594164a49ee0e82b9c4ab826e24e851b10/experiments/warm-town-2d/tanks-warm-town.html).

- **WASD или стрелки** — движение, **мышь** — прицел, **ЛКМ** — огонь в бою и выбор корпуса в подготовке.
- **Enter** — начать волну, **Esc** — пауза или отмена выбора цели укрепления, **Ctrl+Z / ⌘+Z** — отмена последнего действия подготовки.

## Карта и кампания

База стоит на городской площади. Входы A и B находятся с севера, C — с востока. После гибели в бою танк ждёт 4 секунды и возвращается на открытую южную улицу, когда там есть свободное место. Через восточный двор можно выйти на эту улицу по юго-восточному проезду.

В кампании восемь фиксированных волн и 66 противников. Расписание всех атак открывается кнопкой «Кампания». Средние и тяжёлые танки, уничтоженные за пределами зон появления, оставляют корпуса. Корпуса перекрывают движение и огонь. Между волнами их можно оставить на поле, разобрать для ремонта базы, обменять на модуль или потратить на укрепление другого корпуса.

Прогноз маршрутов по умолчанию выключен. Его можно включить под полем в подготовке. Пунктир показывает путь от входа к базе или к первому корпусу, который нужно пробить.

После победы или поражения карточка «Итог попытки» показывает число пройденных волн, уничтоженных танков и созданных корпусов, а также оставшиеся HP базы. Кнопка «Скачать журнал JSON» сохраняет `tanks-attempt.json` с идентификатором сборки `prototype-06-map-lab-warm-town-3`.

## Сборка и проверки

Из каталога `experiments/warm-town-2d` с Node.js 20 или новее:

```sh
node warm-city-src/build.cjs --blockout
node warm-city-src/check.cjs evidence/warm-town/blockout.html
node warm-city-src/build.cjs
node warm-city-src/check.cjs tanks-warm-town.html
node warm-city-src/browser.cjs tanks-warm-town.html /tmp/warm-town-browser-1366
TANKS_CITY_WIDTH=1280 TANKS_CITY_HEIGHT=720 TANKS_CITY_LAYOUT_ONLY=1 \
  node warm-city-src/browser.cjs tanks-warm-town.html /tmp/warm-town-browser-1280
```

`map.cjs` считывает контуры и двери из `art-directions/layout-approved.html`. Контуры разбиваются на прямоугольники для коллизий и остаются цельными для отрисовки. `renderer.js` собирает поверхности кварталов в Canvas из `art/materials.webp`. `base.js` и `vehicles.js` рисуют базу, танки и корпуса из состояния игры. `build.cjs` встраивает оформление и карту в копию Twin Gates. Для проверки в Chrome требуется новый каталог вывода. Сценарий использует планировщик бота из `tools/verify-campaign.cjs` в корне репозитория.

Атлас уже сохранён рядом с исходниками. Для его повторного извлечения из `art-directions/warm-town.png` выполните `python3 warm-city-src/art/build-atlas.py` с Pillow.

Команда `npm test` из корня репозитория проверяет побайтовое совпадение пересобранного HTML, расписание волн и геометрию. Для воспроизводимой сборки исходный HTML Twin Gates зафиксирован в этом каталоге. Игра из корневого `index.html` развивается отдельно.

Браузерный сценарий выше проверяет ранние волны, действия с корпусами и экспорт журнала. При публикации отдельный полный офлайн-прогон в Chrome завершился победой на восьмой волне и скачиванием итогового журнала. [Проверки сборки в PR #30](https://github.com/AidarKhusainov/tanks-for-the-cover/pull/30).
