14 ноября 2026 года. Автономный HTML: SHA-256 `386e50f9f7c939f69a6b718c15ce72109d5cdd2324041fbbf10a65101c9e31e0`, 988548 байт. Это та же сборка, что прошла визуальную проверку перед переносом в Git. [Машиночитаемые результаты](checks.json).

## Объём изменения

В репозиторий добавлена самостоятельная 3D-версия с собственным городским планом. Корневой `index.html` не менялся. Импорт сохраняет исходники и HTML проверенной 3D-сборки. Единственное изменение её сборщика — создание каталога результата для `--blockout`, чтобы команда работала из чистой копии. Сначала новый тест воспроизвёл ENOENT без `evidence/`, затем прошёл после исправления.

В 3D-сборке сохранены восемь волн, три типа врагов, плавное уклонение, корпуса, ремонт, модули, укрепление и отмена. При сравнении с базой PR `d8a8cf8` ядро TankCore после нормализации BUILD_ID отличается только комментарием о точке возрождения; городская карта и представление отдельные.

## Автоматические проверки

- `npm test`: **100/100** на Node.js 20.12.0. Существующий GitHub Actions запускает тот же набор на Node.js 22 для PR.
- `npm run test:3d`: чистая временная копия исходников без готового HTML, повторная детерминированная сборка, побайтное совпадение с HTML в Git, проверка симуляции и создание blockout без заранее подготовленной папки.
- Регрессия геометрии рыночного навеса: вершины остаются в пределах здания. До исправления пропущенной ширины одна из координат высоты была 14007702.
- `node tools/verify-game.cjs tanks-warm-town-3d.html` из каталога эксперимента: целостность ядра и расписания, 8 волн / 66 противников, 11 контуров зданий, 9 вариантов маршрутов, проезды, возврат, столкновения и действия с корпусами.

## Браузер

`npm run test:3d:browser` открывает HTML из репозитория через `file://` с отключённой сетью. Проверены размеры 1366×900 и 1280×720, старт волны, переключение маршрутов, прицел в трёх точках, проезды и столкновения, первая волна обычным вводом, выбор корпуса, ремонт, установка модуля, отмена и выгрузка журнала. Результат и SHA проверенного файла — в `checks.json`.

Для той же побайтной сборки до импорта отдельно проверены:

- `--layout-only --no-float-cache`: при отключённых необязательных float-расширениях WebGL используется обычный цветовой буфер; чтение пикселей дороги, крыши и площади подтверждает видимость города.
- `--recovery-only`: восстановление WebGL возвращает прежние пиксели; после изменения размера окна прицел остаётся точным, состояние игрока не меняется.

Браузерные результаты относятся к автономному HTML, а не к скачиванию с GitHub или HTTP-сервера. Скачивание журнала проверено; скачивание самого HTML через HTTP отдельно не проверялось. В публичной сводке удалены абсолютные локальные пути и сведения о компьютере; исходные CDP-журналы не включены в Git.

## Ограничения

В браузере пройдена первая волна. Вся кампания в этой 3D-карте и человеческий плейтест не проводились; это не завершение исследования #14. Короткие замеры FPS при программном SwiftShader зависят от нагрузки проверочной среды и не заменяют проверку на компьютере игрока.

Независимое ревью проверило импорт, переносимость, сборку, проверки, лицензирование и соответствие отчёта результатам. Файлы исходников Three.js и MIT-лицензия совпадают с архивом three 0.187.0. Для игры и обычной сборки сетевые ресурсы не нужны.
