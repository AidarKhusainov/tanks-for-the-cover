# Tanks for the Cover

Браузерный 2D-прототип игры про танк, защищающий базу. Ключевая механика — уничтожать противников в подходящих местах и использовать оставшиеся корпуса как баррикады или ресурс для ремонта базы.

**Текущая играбельная версия:** [Прототип 05](https://tank-magnetic-prototype.light-ash-3014.chatgpt.site/).

## Что реализовано в опубликованном прототипе

- Управление танком: WASD, наведение и стрельба мышью.
- Четыре волны лёгких и средних противников, три направления атаки.
- Лёгкие танки могут переключаться на игрока и кратковременно преследовать его; средние преимущественно атакуют базу.
- Уничтоженные средние танки оставляют корпуса, которые блокируют перемещение и огонь.
- Между волнами корпуса можно сохранить или разобрать для ремонта базы.
- Защищённая точка возрождения; враги стреляют без дополнительного предупреждения.

Репозиторий подготовлен к переносу исходников. **Исходный код опубликованной версии 05 и её автоматические тесты пока не перенесены**: они хранятся в отдельном проекте прототипа и не доступны из текущего рабочего окружения. Этот README не является самостоятельной запускаемой сборкой.

Актуальный проектный документ — *Prototype Design Document v0.5*. Идеи о детонации боеукладки и переделке защищённой ниши пока не реализованы.
