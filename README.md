# Tanks for the Cover

Браузерный 2D-прототип игры про танк, защищающий базу. Основная механика — уничтожать противников в подходящих местах и использовать оставшиеся корпуса как баррикады либо разбирать их для ремонта базы.

**Версия:** прототип 05. [Играть в опубликованную версию](https://tank-magnetic-prototype.light-ash-3014.chatgpt.site/).

## Запуск

Скачай репозиторий и открой **`index.html`** в настольном браузере. Игра полностью автономная: не нужны сервер, Java, npm или внешние ресурсы.

Через Git:

```bash
git clone https://github.com/AidarKhusainov/tanks-for-the-cover.git
cd tanks-for-the-cover
```

Затем открой `index.html` двойным щелчком. Ссылка «Скачать для игры офлайн» сохраняет этот же HTML под именем `tank-prototype.html`.

## Управление

- `WASD` — движение; мышь — прицеливание.
- Удержание левой кнопки мыши — огонь.
- В подготовке щёлкни по корпусу для разбора или сохранения.
- `Ctrl+Z` — отмена разбора, `Enter` — начать волну, `Esc` — пауза.

## Что реализовано

Четыре волны, три направления наступления, лёгкие противники с коротким преследованием игрока и средние с приоритетом базы. Враги стреляют при готовом оружии без дополнительного предупреждения. Средние танки оставляют корпуса, которые меняют движение и огонь. Между волнами корпуса можно оставить или разобрать для ремонта базы. Возрождение игрока происходит в защищённой нише.

Обсуждавшиеся [взрыв боеукладки](docs/ideas/ammo-rack-detonation.md) и замена ниши **не реализованы**.

## Проверки

Для автоматических тестов симуляции нужен Node.js 20 или новее:

```bash
npm test
```

Тесты используют встроенный `node:test` без внешних зависимостей. Общий загрузчик исполняет первые два JS-блока `index.html` с данными карты и ядром симуляции. Набор покрывает:

- движение, столкновения, защиту и выход из ниши, проходы A/B/C, обходы и заторы;
- выстрелы и попадания, выбор цели и готовность оружия, погоню лёгкого танка;
- границы зон и очередь появления, создание и срок службы корпусов, завершение волн, возвращение игрока, паузу и сброс;
- ремонт базы и цепочку отмены в подготовке.

GitHub Actions запускает `npm test` на Node.js 22 при push в `master` и при pull request. Проверки выбора точного пролома и конца линии предпросмотра относятся к [#5](https://github.com/AidarKhusainov/tanks-for-the-cover/issues/5). Браузерный ввод, отрисовку, звук и автономный запуск проверяют отдельно в [#4](https://github.com/AidarKhusainov/tanks-for-the-cover/issues/4), игровой баланс и интерес — в плейтесте [#14](https://github.com/AidarKhusainov/tanks-for-the-cover/issues/14).

## Структура

- `index.html` — полный самодостаточный игровой прототип: разметка, стили, сценарии, логика симуляции и интерфейс.
- `tests/` — smoke-тесты, регрессионные сценарии симуляции и общий загрузчик ядра.
- `package.json` — команда тестирования, не требуется для игры.
- `.github/workflows/ci.yml` — автоматическая проверка.

## Документация и дальнейшая работа

Prototype Design Document — [v0.5 от 12 ноября 2026 года](docs/prototype-design-document.md). Markdown-версия исходного DOCX с сохранением правил, таблиц и схемы карты.

Раздел 14 сохраняет результаты проверок исходного проекта `tank-prototype`. Это отчёты исходной сборки, а не результаты запуска тестов этого репозитория; доступные здесь проверки описаны выше.

Исходный код пока оставлен внутри одного HTML, как в переданном прототипе. Это позволяет воспроизвести игру без изменения механик. В дальнейшем сценарии, игровую симуляцию, представление и стили можно выделить в отдельные файлы с сохранением тестов и поведения.
