# Tanks for the Cover

Браузерный 2D-прототип игры про танк, защищающий базу. Основная механика — уничтожать противников в подходящих местах и использовать оставшиеся корпуса как баррикады либо разбирать их для ремонта базы.

**Версия:** прототип 05. [Играть в опубликованную версию](https://tank-magnetic-prototype.light-ash-3014.chatgpt.site/).

## Запуск

Скачай репозиторий и открой **`index.html`** в настольном браузере. Игра полностью автономная: не нужны сервер, Java, npm или внешние ресурсы.

Через Git:

```bash
git clone https://github.com/AidarKhusainov/tanks-for-the-cover.git
cd tanks-for-the-cover
```

Затем открой `index.html` двойным щелчком. Ссылка «Скачать для игры офлайн» сохраняет этот же HTML под именем `tank-prototype.html`.

## Управление

- `WASD` — движение; мышь — прицеливание.
- Удержание левой кнопки мыши — огонь.
- В подготовке щёлкни по корпусу для разбора или сохранения.
- `Ctrl+Z` — отмена разбора, `Enter` — начать волну, `Esc` — пауза.

## Что реализовано

Четыре волны, три направления наступления, лёгкие противники с коротким преследованием игрока и средние с приоритетом базы. Враги стреляют при готовом оружии без дополнительного предупреждения. Средние танки оставляют корпуса, которые меняют движение и огонь. Между волнами корпуса можно оставить или разобрать для ремонта базы. Возрождение игрока происходит в защищённой нише.

Обсуждавшиеся [взрыв боеукладки](docs/ideas/ammo-rack-detonation.md) и замена ниши **не реализованы**.

## Проверки

Для автоматических smoke-тестов нужен Node.js 20 или новее:

```bash
npm test
```

Тесты используют встроенный `node:test`, без внешних зависимостей. Они загружают первые два JS-блока из HTML и проверяют ключевые правила симуляции. Это **12 дополнительных проверок**, а не полный комплект исторических QA-тестов предыдущей сборки. На GitHub они также запускаются через Actions при push и pull request.

## Структура

- `index.html` — полный самодостаточный игровой прототип: разметка, стили, сценарии, логика симуляции и интерфейс.
- `tests/core.test.cjs` — smoke-тесты игровой логики.
- `package.json` — команда тестирования, не требуется для игры.
- `.github/workflows/ci.yml` — автоматическая проверка.
