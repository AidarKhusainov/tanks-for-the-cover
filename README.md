# Tanks for the Cover

Браузерный 2D-прототип игры про танк, защищающий базу. Основная механика — уничтожать противников в подходящих местах и использовать оставшиеся корпуса как баррикады либо разбирать их для ремонта базы, получения модуля или укрепления другого корпуса.

**Версия:** прототип 05. [Играть в опубликованную версию](https://tank-magnetic-prototype.light-ash-3014.chatgpt.site/).

## Запуск

Скачай репозиторий и открой **`index.html`** в настольном браузере. Игра полностью автономная: не нужны сервер, Java, npm или внешние ресурсы.

Через Git:

```bash
git clone https://github.com/AidarKhusainov/tanks-for-the-cover.git
cd tanks-for-the-cover
```

Затем открой `index.html` двойным щелчком. Ссылка «Скачать для игры офлайн» сохраняет этот же HTML под именем `tank-prototype.html`.

## Управление

- `WASD` — движение; мышь — прицеливание.
- Удержание левой кнопки мыши — огонь.
- В подготовке щёлкни по корпусу для разбора, сохранения или укрепления. Для укрепления выбери донора, нажми «Укрепить другой корпус», выбери цель на поле и подтверди расход.
- `Ctrl+Z` — отмена последнего действия подготовки, `Enter` — начать волну, `Esc` — пауза или выход из выбора цели укрепления.

## Что реализовано

Четыре волны, три направления наступления, лёгкие противники с коротким преследованием игрока и средние с приоритетом базы. Враги стреляют при готовом оружии без дополнительного предупреждения. Средние танки оставляют корпуса, которые меняют движение и огонь. В подготовке прогноз показывает маршруты от входов к базе или до первого корпуса для пролома. Между волнами корпуса можно оставить, разобрать для ремонта базы, обменять на модуль или потратить на укрепление другого корпуса. Возрождение игрока происходит в защищённой нише.

Симуляция и интерфейс поддерживают тяжёлого танка и тяжёлый корпус. Средний корпус служит одну следующую волну и даёт до 30 HP ремонта, тяжёлый — две волны и до 50 HP. Средний корпус даёт двигатель (5 ед/с, 60 HP), тяжёлый — броню (4 ед/с, 90 HP). В танке один слот. Укрепление восстанавливает до половины максимальной прочности цели, добавляет одну волну службы и отмечается стрелкой ↑ у корпуса. Каждую цель можно укрепить один раз. Укрепление, смена модуля и ремонт отменяются в обратном порядке, с возвратом корпусов и танка на позицию перед действием. При гибели модуль сохраняется, при новой попытке слот пуст. Тяжёлый пока появляется только в тестовых сценариях; его выходы в кампании предусмотрены в [#9](https://github.com/AidarKhusainov/tanks-for-the-cover/issues/9).

Обсуждавшиеся [взрыв боеукладки](docs/ideas/ammo-rack-detonation.md) и замена ниши **не реализованы**.

## Проверки

Для автоматических тестов симуляции нужен Node.js 20 или новее:

```bash
npm test
```

Тесты используют встроенный `node:test` без внешних зависимостей. Общий загрузчик исполняет первые два JS-блока `index.html` с данными карты и ядром симуляции. Набор покрывает:

- движение, столкновения, защиту и выход из ниши, проходы A/B/C, обходы и заторы;
- выстрелы и попадания, выбор цели и готовность оружия, погоню лёгкого танка;
- границы зон и очередь появления, создание и срок службы корпусов, завершение волн, возвращение игрока, паузу и сброс;
- ремонт базы, параметры и замену модулей, укрепление за донора, смешанную цепочку отмены и сохранение модуля при возвращении танка;
- выбор пролома по числу разных корпусов и длине пути, пересчёт маршрута и конец линии предпросмотра.

GitHub Actions запускает `npm test` на Node.js 22 при push в `master` и при pull request. Браузерный ввод, отрисовку, звук и автономный запуск проверяют отдельно в [#4](https://github.com/AidarKhusainov/tanks-for-the-cover/issues/4), игровой баланс и интерес — в плейтесте [#14](https://github.com/AidarKhusainov/tanks-for-the-cover/issues/14).

## Структура

- `index.html` — полный самодостаточный игровой прототип: разметка, стили, сценарии, логика симуляции и интерфейс.
- `tests/` — smoke-тесты, регрессионные сценарии симуляции и общий загрузчик ядра.
- `package.json` — команда тестирования, не требуется для игры.
- `.github/workflows/ci.yml` — автоматическая проверка.
